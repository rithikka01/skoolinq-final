Skoolinq – AI-Powered Career Guidance Application

Skoolinq is a student-focused mobile application designed to help students explore career opportunities, discover higher-education pathways, and make informed academic and professional decisions. Built using Flutter and Firebase, the application aims to make career guidance more accessible through an intuitive and user-friendly interface.

🎥 Demo

Watch the Skoolinq Demo Video - https://drive.google.com/file/d/1phh2_o6zBKQM4_hzDQxbiMMZjr45S3Ro/view?usp=sharing

🚀 Features

Career Exploration: Helps students explore potential career paths based on their interests and goals.

Higher Education Guidance: Provides information about educational opportunities and academic pathways.

Career Recommendations: Supports students in exploring relevant career and education options.

Intuitive User Interface: Provides a simple and user-friendly mobile experience.

Firebase Integration: Supports backend functionality and data management.

🛠️ Tech Stack

Flutter – Cross-platform mobile application development

Dart – Application programming language

Firebase – Backend services and data management

⚙️ Getting Started

Prerequisites

Flutter SDK

Dart SDK

Android Studio or Visual Studio Code

Git

Installation

1. Clone the repository

git clone https://github.com/rithikka01/skoolinq-final.git

2. Navigate to the project directory

cd skoolinq-final

3. Install dependencies

flutter pub get

4. Configure Firebase

Configure the required Firebase project settings if your application uses Firebase.

5. Run the application

flutter run
